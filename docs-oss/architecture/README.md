# Architecture overview

Four ideas carry the codebase. Everything else is detail.

## 1. Vertical slices

Each feature is a self-contained slice under `pkg/weave/<name>/`: routes, handler,
service, store, and schema builders in one directory. A slice owns its data and
its rules; it does not reach into another slice's internals. Cross-slice reads go
through narrow reader interfaces declared by the consumer.

There are two slice shapes — **full slices** that own a table, and
**handler-only modules** that compose data from several slices without owning any.
[`slices.md`](slices.md) explains the distinction and when to use each;
[ADR-0001](../decisions/0001-weave-module-shapes.md) records why.

## 2. Schema-driven API

The backend emits a JSON schema describing structure, data, capabilities, and
mutation URLs. The frontend renders it generically with no domain knowledge — it
never constructs an API URL, infers a permission, or branches on entity type. The
schema is the complete contract. See [`schema-driven-ui.md`](schema-driven-ui.md)
and [`../principles.md`](../principles.md).

## 3. Svelte islands

Interactive components mount into server-rendered Go templates. There is no SPA.
A `.gohtml` page renders the chrome and drops a `data-island` element; a small
TypeScript entry mounts a Svelte component into it; the component fetches its
schema and renders. See [`svelte-islands.md`](svelte-islands.md).

## 4. pgx + sqlc + goose

The PostgreSQL data layer: typed queries generated by sqlc, schema migrations
managed by goose and applied at boot. No ORM. Each slice owns a `Store` backed by
generated queries. See [`data-layer.md`](data-layer.md).

## How they fit together

```
HTTP request
  │
  ├─ chi router  ──────────────────────────────► slice routes
  │
  ▼
handler (slice)            depends only on its *Service
  │
  ▼
service (slice)            validation · permissions · business rules
  │                        builds the schema; maps errors to apierror
  ▼
store (slice)              pgx + sqlc queries against its table
  │
  ▼
PostgreSQL                 goose-migrated schema

response: a JSON schema (for management UI) or a domain DTO (for rich editors)
  │
  ▼
Svelte island             renders the schema generically — no domain knowledge
```

The boundaries are the point: a handler never touches the pool, a renderer never
branches on entity type, a slice never imports another slice. Each rule has a doc
and, where it cost something to decide, an ADR.
