# Code of Conduct

This project adopts the [Contributor Covenant Code of Conduct, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

By participating in this project — through issues, pull requests, discussions, or any other channel — you agree to abide by its terms.

## Reporting

Reports of unacceptable behavior should be sent to:

> **sjoerd.siebinga@gmail.com**

Use the subject prefix `[pletka conduct]`. All reports will be reviewed and investigated promptly and fairly. The privacy and safety of the reporter will be respected.

## Enforcement

Project maintainers are responsible for clarifying and enforcing standards of acceptable behavior, and will take appropriate and fair corrective action in response to any behavior they deem inappropriate, threatening, offensive, or harmful. The full enforcement guidelines are described in the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).

## Scope

This Code of Conduct applies within all project spaces — repositories, issue trackers, discussions, chat channels, and project events — and also when an individual is officially representing the project in public spaces.
